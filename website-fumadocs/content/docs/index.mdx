## A learning path built for clarity

These courses explain modern AI in simple English while keeping the technical terms you need. Each lesson includes practical examples, exercises, review material, and a link to the original Agent Factory / Panaversity source.

<LearningCallout tone="note">

**Recommended approach:** begin with Course 1 and continue in sequence. Later courses build on ideas introduced earlier, especially delegation, verification, and human responsibility.

</LearningCallout>

## What the sequence covers

1. Delegating bounded work to AI
2. Understanding what language models actually do
3. Building practical AI fluency
4. Writing useful prompts and briefings
5. Turning structured Markdown into readable HTML
6. Commissioning and verifying AI-generated code
7. Reusing methods with Skills and connecting apps safely
8. Protecting human judgment in AI-assisted work
9. Designing and diagnosing reliable workflows
10. Governing AI use, risk, and accountability

Start with [Just Delegate It](/courses/just-delegate-it), or use the sidebar to choose a course.
